# CS-320-Software-Test-Automation

## How can I ensure that my code, program, or software is functional and secure?

I ensure that my software is functional and secure by following a structured testing process and applying software engineering best practices. Throughout this course, I used JUnit testing to 
verify that classes and services met all specified requirements and handled both valid and invalid inputs appropriately. I created unit tests that evaluated expected behavior, boundary conditions,
and exception handling to uncover defects before deployment.

Security is also an important aspect of software quality. By validating user input, enforcing constraints, and preventing invalid data from entering the system, I can reduce the likelihood of 
errors and vulnerabilities. Automated testing helps ensure that changes to the code do not introduce new defects and that the software continues to perform as intended.

## How do I interpret user needs and incorporate them into a program?

I interpret user needs by carefully reviewing project requirements and translating them into specific software features and validation rules. During this course, the requirements defined how 
contact, task, and appointment information should be created, stored, and modified. I used those requirements to design classes with appropriate attributes, validation logic, and service methods.

To incorporate user needs effectively, I break requirements into smaller functional components and create tests that verify each requirement has been implemented correctly. This approach helps 
ensure that the final program behaves as expected and provides the functionality requested by the user.

## How do I approach designing software?

I approach software design by first understanding the requirements and identifying the necessary components of the system. I focus on creating modular, maintainable code by separating 
responsibilities between classes and services.

I also design software with testing in mind. By developing clear interfaces and using object-oriented principles, I can create code that is easier to test, maintain, and expand in the future. 
Throughout this course, I learned that thoughtful design combined with comprehensive testing leads to higher-quality software and more reliable applications.
